# 🌐 TCP/IP Model

## What is TCP/IP?
TCP/IP stands for **Transmission Control 
Protocol / Internet Protocol**.

It is a set of rules that defines how data 
is sent and received over the internet.

**Real life example:** Just like traffic rules 
tell us how to drive on roads — TCP/IP tells 
devices how to send data on a network!

## TCP/IP has 4 Layers

### Layer 4 - Application Layer
- User directly interacts here
- Handles emails, web browsing, file transfer
- Protocols: HTTP, FTP, SMTP, DNS

### Layer 3 - Transport Layer
- Breaks data into packets
- Ensures data reaches correctly
- Two protocols:
  - **TCP** — Reliable, slower
  - **UDP** — Fast, but no guarantee

### Layer 2 - Internet Layer
- Finds best path for data
- Uses IP addresses
- Protocol: IP, ICMP

### Layer 1 - Network Access Layer
- Physical transmission of data
- Cables, WiFi signals
- Protocol: Ethernet, WiFi

## TCP vs UDP

| | TCP | UDP |
|--|--|--|
| Full form | Transmission Control Protocol | User Datagram Protocol |
| Reliable? | Yes | No |
| Speed | Slower | Faster |
| Example | File download, Email | Video call, Gaming |

## OSI vs TCP/IP

| OSI | TCP/IP |
|--|--|
| 7 Layers | 4 Layers |
| Theoretical model | Practical model |
| Used for learning | Used in real world |
