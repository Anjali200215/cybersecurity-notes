# 💻 Computer Networks

## What is a Computer Network?
A computer network is a group of two or more 
computers/devices connected together to 
share data and resources.

**Real life example:** In your school, all 
computers in the computer lab are connected 
together — that is a computer network!

## Why do we need Networks?
- Share files and data easily
- Share resources like printers
- Communication — email, video calls
- Access the internet

## How are Networks Connected?

### Wired Connection
- Devices connected using cables
- Faster and more stable
- Example: LAN cable (Ethernet)

### Wireless Connection
- Devices connected without cables
- Using WiFi or Bluetooth
- Example: Your phone connected to WiFi

## Key Devices in a Network

### Router
- Connects different networks together
- Sends data to the correct destination
- Example: Your home WiFi router

### Switch
- Connects devices within the same network
- Example: Office switch connecting all computers

### Hub
- Older device, sends data to ALL devices
- Less efficient than a switch

## Important Terms
- **Node** — Any device in a network 
  (computer, phone, printer)
- **Bandwidth** — Speed of data transfer
- **Protocol** — Rules for communication 
  in a network
