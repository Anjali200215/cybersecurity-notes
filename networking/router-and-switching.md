# 🔀 Router & Switching

## What is a Router?
A router is a device that connects 
different networks together and sends 
data to the correct destination.

**Real life example:** A router is like 
a postman — it reads the address and 
delivers data to the correct device!

## How Router Works?
- Receives data packets
- Reads the IP address
- Finds the best path
- Sends data to correct destination

## What is a Switch?
A switch is a device that connects 
multiple devices within the same network.

**Real life example:** A switch is like 
a telephone exchange — it connects the 
right two people together!

## How Switch Works?
- Receives data from one device
- Reads the MAC address
- Sends data ONLY to the correct device
- More efficient than a Hub

## Router vs Switch

| | Router | Switch |
|--|--|--|
| Connects | Different networks | Same network |
| Address used | IP Address | MAC Address |
| Example | Home WiFi router | Office switch |
| Layer | Layer 3 (Network) | Layer 2 (Data Link) |

## What is Switching?
Switching is the process of forwarding 
data packets from one device to another 
within the same network.

## Types of Switching

### Circuit Switching
- A dedicated path is set before communication
- Example: Old telephone calls

### Packet Switching
- Data is broken into packets
- Each packet can take different path
- Example: Internet data transfer

### Message Switching
- Entire message is stored then forwarded
- Example: Email

## Key Difference
- **Router** = Connects your home to the Internet
- **Switch** = Connects devices inside your home/office
