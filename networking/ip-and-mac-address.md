# 📍 IP Address & MAC Address

## What is an IP Address?
IP stands for **Internet Protocol**.
An IP address is a unique address assigned 
to every device on a network.

**Real life example:** Just like your home 
has a postal address — every device has 
an IP address so data can be delivered 
to the correct device!

## Types of IP Address

### IPv4
- Most common type
- Format: 4 numbers separated by dots
- Example: 192.168.1.1
- Total possible addresses: 4.3 billion

### IPv6
- Newer version of IP
- Created because IPv4 addresses are running out
- Format: 8 groups of hexadecimal numbers
- Example: 2001:0db8:85a3:0000:0000:8a2e:0370:7334
- Much more addresses available

## Types of IP Based on Usage

### Private IP
- Used inside a local network
- Not visible on the internet
- Example: 192.168.1.1 (your home router)

### Public IP
- Assigned by your Internet Service Provider
- Visible on the internet
- Example: The IP your ISP gives your home

### Static IP
- Never changes
- Example: Web servers

### Dynamic IP
- Changes every time you connect
- Example: Your home internet connection

## What is a MAC Address?
MAC stands for **Media Access Control**.
It is a unique address assigned to every 
network device by the manufacturer.

**Real life example:** Just like every person 
has a unique fingerprint — every network 
device has a unique MAC address!

## Key Features of MAC Address
- Permanently assigned by manufacturer
- Cannot be changed (usually)
- 48 bits long
