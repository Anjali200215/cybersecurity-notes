# 🖧 LAN (Local Area Network)

## What is LAN?
LAN is a network that connects devices 
in a small geographical area like a 
home, school, or office.

**Real life example:** All computers in 
your school computer lab connected 
together — that is a LAN!

## Key Features of LAN
- Covers a small area
- High speed data transfer
- Less expensive to set up
- Private network — not public

## How LAN Works?
All devices are connected through a 
**switch or router** and can share:
- Files and folders
- Printers
- Internet connection

## Types of LAN Connection

### Wired LAN
- Connected using Ethernet cables
- Faster and more stable
- Example: Office computers connected 
  with LAN cables

### Wireless LAN (WLAN)
- Connected using WiFi
- No cables needed
- Example: Your home WiFi network

## Common Uses of LAN
- School computer labs
- Office networks
- Home networks
- Gaming — multiplayer games use LAN

## LAN vs WAN
| | LAN | WAN |
|--|--|--|
| Area | Small | Large |
| Speed | Fast | Slower |
| Cost | Cheap | Expensive |
| Example | Home WiFi | Internet |
