# 🌐 DHCP (Dynamic Host Configuration Protocol)

## What is DHCP?
DHCP is a protocol that **automatically assigns 
IP addresses** to devices on a network.

**Real life example:** When you connect your 
phone to WiFi, you don't manually type an IP 
address — DHCP does it automatically for you!

## How DHCP Works? (4 Steps)

### Step 1 - DISCOVER
- Device joins the network and says 
  "I need an IP address!"

### Step 2 - OFFER
- DHCP Server replies "I have this IP for you!"

### Step 3 - REQUEST
- Device says "Yes, I'll take that IP!"

### Step 4 - ACKNOWLEDGE
- Server says "Done! That IP is yours now."

## Key Points
- DHCP Server assigns IP addresses automatically
- Without DHCP, you would have to manually 
  set IP address on every device
- IP address given by DHCP is temporary 
  (called a "lease")

## Where is DHCP Used?
- Home WiFi router acts as DHCP server
- Office networks
- Mobile networks
