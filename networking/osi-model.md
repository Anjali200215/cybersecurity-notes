# 🔗 OSI Model

## What is OSI Model?
OSI stands for **Open Systems Interconnection**.
It is a framework that explains how data travels 
from one device to another over a network.
It has **7 layers** — each layer has a specific job.

## The 7 Layers (Top to Bottom)

### Layer 7 - Application Layer
- What the user directly interacts with
- Example: Browser, Email, WhatsApp

### Layer 6 - Presentation Layer
- Converts data into a format the app can understand
- Handles encryption and compression
- Example: SSL/TLS encryption

### Layer 5 - Session Layer
- Manages connections between devices
- Opens, maintains, and closes sessions
- Example: Login session on a website

### Layer 4 - Transport Layer
- Responsible for end-to-end delivery of data
- Uses TCP (reliable) and UDP (fast)
- Example: File download uses TCP

### Layer 3 - Network Layer
- Finds the best path to send data
- Uses IP addresses
- Example: Router works at this layer

### Layer 2 - Data Link Layer
- Transfers data between two directly connected devices
- Uses MAC addresses
- Example: Switch works at this layer

### Layer 1 - Physical Layer
- Actual physical connection
- Example: Cables, WiFi signals, fiber optics

## Easy Trick to Remember!
**"All People Seem To Need Data Processing"**
Application, Presentation, Session, Transport, 
Network, Data Link, Physical
