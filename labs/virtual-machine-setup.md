# 🖥️ Virtual Machine Lab Setup

## What is a Virtual Machine?
A Virtual Machine (VM) is a software-based 
computer that runs inside your real computer.

**Real life example:** Like having multiple 
phones inside one phone — each works 
independently without affecting the others!

## Why use VMs in Cybersecurity?
- Practice safely without damaging your real PC
- Test attacks and defenses in a safe environment
- Build a home lab for hands-on learning
- Required skill for SOC Analyst roles

## What is pfSense?
pfSense is a free firewall and router software. 
It controls what network traffic is allowed 
or blocked.

## What is Windows Server?
An operating system made for managing 
networks, users, and services in organizations.
